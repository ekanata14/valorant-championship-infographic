    Temuan

    Sumber data

    VLR.gg — dataset “Valorant Champion Tour 2021–2026 Data” oleh Ryan Luong (Kaggle, MIT), di-scrape dari vlr.gg.

    Tabel: all_ids, matches/scores.csv (pemenang), matches/overview.csv (lineup & performa).

    Logo event/tim dan foto pemain: VLR.gg (og:image), diperkecil dan disematkan.

    Metode

    • {{RAWROWS}} baris dibaca · {{EXCLUDED}} dikeluarkan (peta kosong/TBD).
    • Turnamen = nama unik: {{TOURNAMENTS}} nama, {{TOURNAMENT_IDS}} ID ({{DUP_TOURNAMENTS}} nama punya dua ID).
    • Pemenang = skor final dari scores.csv; final dideteksi dari match type (Grand Final/Final).
    • Performa pemain = agregat overview.csv per turnamen (rating, ACS, K/D, W–L).
    • Wilayah = kata kunci nama turnamen.
    • Varian Open Qualifier #1/#2 digabung.

    Keterbatasan

    • Juara hanya diisi bila final & skornya terdeteksi; beberapa turnamen liga tanpa final.
    • Partisipasi pemain per pertandingan, bukan per peta; beberapa laga tanpa data lineup.
    • Cakupan tidak merata ({{COVERAGE}}% di 2021–2022).
    • Data {{YEAR_MAX}} kemungkinan belum lengkap.
    • Wilayah heuristik; tier turnamen dikurasi manual untuk major.
